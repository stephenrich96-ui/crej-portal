# Logo Setup

To add your logo to the CREJ Portal:

1. Place your logo file as `logo.png` in this directory (`/public/logo.png`)
2. Recommended size: 200x200px or similar square aspect ratio
3. Supported formats: PNG (recommended), SVG, JPG
4. The logo will automatically appear in:
   - Header (mobile and desktop)
   - Sidebar navigation
   - If logo is not found, a fallback "C" icon will be displayed

The logo will be automatically sized and styled to match the premium design.
