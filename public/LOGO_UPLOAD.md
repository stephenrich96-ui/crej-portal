# 🖼️ HOW TO ADD YOUR LOGO

## Quick Steps:

1. **Get your logo file** (PNG, JPG, or SVG)

2. **Name it exactly:** `logo.png` (or `logo.jpg` or `logo.svg`)

3. **Place it here:** `/Users/stephenrichardson/crej-portal/public/logo.png`

## How to Upload:

### Using Finder (Mac):
1. Open Finder
2. Press `Cmd + Shift + G`
3. Type: `/Users/stephenrichardson/crej-portal/public`
4. Drag your logo file here
5. Rename it to `logo.png` if needed

### Using Terminal:
```bash
# Copy your logo
cp /path/to/your/logo.png /Users/stephenrichardson/crej-portal/public/logo.png
```

### Using VS Code / Cursor:
1. Open `public/` folder
2. Drag logo file there
3. Rename to `logo.png`

## After Uploading:

1. Refresh your browser (Cmd+Shift+R)
2. Logo should appear in the sidebar!

## Supported Formats:
- PNG (recommended)
- JPG
- SVG

## Note:
If no logo is found, the app will show a "C" icon as a fallback.
