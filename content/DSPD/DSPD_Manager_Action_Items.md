# DSPD Manager Action Items & Responsibilities

## 🎯 New Support Coordinator Onboarding (Manager Tasks)

### Pre-Hire Phase
- [ ] Post position and screen candidates
- [ ] Conduct interviews
- [ ] Complete background checks
- [ ] Verify credentials and certifications
- [ ] Make offer and set start date

### Pre-First Day (Complete 1 week before start)
- [ ] **System Access Setup**
  - [ ] Request Health E account creation
  - [ ] Set up MyCase access
  - [ ] Create email account
  - [ ] Configure phone/voicemail
  - [ ] Issue office keys and access cards
  - [ ] Test all system access

- [ ] **Workspace Preparation**
  - [ ] Prepare desk/workstation
  - [ ] Ensure computer and equipment ready
  - [ ] Stock supplies
  - [ ] Prepare welcome packet

- [ ] **Training Materials Preparation**
  - [ ] Verify all training links work
  - [ ] Ensure training videos accessible
  - [ ] Prepare sample case files for review
  - [ ] Create training schedule
  - [ ] Assign mentor/shadow coordinator

### First Day
- [ ] Welcome meeting and introductions
- [ ] Tour of office and facilities
- [ ] Review onboarding checklist together
- [ ] Set up training schedule
- [ ] Introduce to team
- [ ] Review first week expectations

### Week 1 Manager Tasks
- [ ] **Daily Check-ins** (15-30 minutes)
  - Review training progress
  - Answer questions
  - Address concerns
  - Provide encouragement

- [ ] **Training Verification**
  - [ ] Verify completion of foundation training
  - [ ] Review quiz results
  - [ ] Observe system navigation skills
  - [ ] Check understanding of role

- [ ] **Resource Access**
  - [ ] Ensure all links/bookmarks work
  - [ ] Verify access to training materials
  - [ ] Confirm system logins functional

### Week 2-4 Manager Tasks
- [ ] **Weekly Progress Reviews**
  - Review training completion
  - Assess competency development
  - Identify areas needing additional support
  - Adjust training plan as needed

- [ ] **Skill Verification**
  - [ ] Observe form completion
  - [ ] Review sample documentation
  - [ ] Verify understanding of procedures
  - [ ] Check compliance knowledge

- [ ] **Shadowing Coordination**
  - [ ] Assign experienced coordinator for shadowing
  - [ ] Schedule client visit observations
  - [ ] Arrange service planning meeting observations
  - [ ] Review case file examples together

### Month 2-3 Manager Tasks
- [ ] **Caseload Management**
  - [ ] Gradually assign clients (start with 2-3)
  - [ ] Monitor case management quality
  - [ ] Review all documentation before submission
  - [ ] Provide feedback and coaching

- [ ] **Competency Assessment**
  - [ ] Complete competency checklist
  - [ ] Verify all training completed
  - [ ] Assess readiness for independent work
  - [ ] Document assessment results

- [ ] **Ongoing Support**
  - [ ] Continue regular check-ins
  - [ ] Address questions and concerns
  - [ ] Provide additional training as needed
  - [ ] Celebrate milestones and progress

## 📋 Ongoing Manager Responsibilities

### Weekly Tasks
- [ ] **Team Meeting** (1 hour)
  - Review caseload status
  - Address questions and concerns
  - Share updates and best practices
  - Problem-solve challenges

- [ ] **Quality Review** (2-3 hours)
  - Review random sample of documentation
  - Check compliance with requirements
  - Verify timeliness of submissions
  - Provide feedback

- [ ] **Support & Coaching** (as needed)
  - Answer questions
  - Provide guidance on complex cases
  - Review difficult situations
  - Offer professional development

### Monthly Tasks
- [ ] **Performance Reviews**
  - Review each coordinator's caseload
  - Assess quality metrics
  - Identify training needs
  - Set goals for next month

- [ ] **Compliance Audit**
  - Review all ISO forms for accuracy
  - Verify service plans are current
  - Check annual reviews completed on time
  - Ensure documentation standards met

- [ ] **Training Updates**
  - Review new DSPD requirements
  - Update training materials as needed
  - Schedule refresher training if required
  - Share policy changes with team

### Quarterly Tasks
- [ ] **Comprehensive Review**
  - Review all coordinator performance
  - Assess team training needs
  - Update procedures and processes
  - Plan professional development

- [ ] **DSPD Compliance Check**
  - Verify all requirements met
  - Review audit findings
  - Address any compliance issues
  - Update documentation as needed

## 🚨 Critical Manager Actions

### When Issues Arise
- [ ] **Documentation Problems**
  - Review specific issues immediately
  - Provide targeted training
  - Set clear expectations
  - Follow up to verify improvement

- [ ] **Compliance Concerns**
  - Address immediately
  - Review with coordinator
  - Implement corrective action
  - Document resolution

- [ ] **Client Safety Issues**
  - Respond immediately
  - Follow crisis protocols
  - Document thoroughly
  - Provide support to coordinator

- [ ] **Performance Issues**
  - Meet one-on-one
  - Identify root causes
  - Create improvement plan
  - Set clear expectations and timeline
